📊 Statistical Modeling and Computing — Coursework Archive

This folder contains graded assignments from the Statistical Modeling and Computing course completed as part of the M.S. in Data Science at Rutgers University.
The course combined statistical theory with hands-on computation in R, focusing on regression modeling, simulation methods, and causal inference.


📂 Contents

	•	 hw1_manideep.pdf	-- Foundational linear regression — least squares estimation, residual diagnostics, and model fit evaluation.
  
	•	 hw2_manideep.pdf	-- 	Multiple regression with interaction terms, model selection via AIC/BIC, and multicollinearity assessment.
  
	•	 manideep_HW3.pdf	-- 	Model comparison using 5-fold cross-validation on birthrate data; analysis of covariate importance and predictive error.
  
	•	 HW4.pdf	-- 	Polynomial regression and bias–variance tradeoff exploration; introduction to ridge and lasso regularization.
  
	•	 hw5_manideep.pdf	-- 	Logistic regression — odds ratios, maximum likelihood estimation, and interpretation of binary outcomes.
  
	•	 HW6.pdf	-- 	Generalized Linear Models (GLMs) for biological response data; binomial and Poisson model fitting.
  
	•	 HW7.pdf	-- 	Resampling methods — bootstrap and jackknife estimators of bias and variance.
  
	•	 HW9.pdf	-- 	Causal inference through randomized experiments; simulation of treatment effects and Neyman variance estimation.
  
	•	 Manideep_HW10.pdf	-- 	Doubly Robust and AIPW estimators implemented via Monte Carlo simulation; evaluation of bias and efficiency.
  
	•	 Manideep-stat-appendix.pdf	-- 	Extended appendix containing simulation diagnostics, additional plots, and summary tables.



🧠 Key Learning Outcomes

	•	Built and interpreted linear, logistic, and generalized linear models using real and simulated data.
  
	•	Applied resampling and simulation techniques (bootstrap, jackknife, and Monte Carlo) to estimate uncertainty.
  
	•	Conducted model selection and validation using cross-validation, AIC/BIC, and regularization.
  
	•	Implemented causal inference frameworks — difference-in-means, regression adjustment, and doubly robust estimators.
  
	•	Developed reproducible analytical workflows in R Markdown with integrated code, analysis, and visualization.
