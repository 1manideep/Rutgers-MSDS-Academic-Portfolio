💎 Data Mining — Coursework Archive

This folder contains selected assignments from the Data Mining course completed as part of the M.S. in Data Science at Rutgers University.
The coursework focused on implementing supervised and unsupervised learning algorithms, understanding bias–variance tradeoffs, and evaluating model performance through cross-validation.
All work was done in R, with code written in R Markdown and rendered into reproducible PDF reports.


📂 Contents

	•	 mining_HW1_Manideep.pdf	Regression experiments exploring regularization, ridge vs. lasso comparison, and subset selection on simulated data.
  
	•	 hw2_mining.pdf	R Markdown–generated report covering model selection, feature interactions, and cross-validation for classification tasks.
  
	•	 HW3.pdf	Advanced modeling using smoothing splines, GAMs, regression trees, and boosting on real-world datasets such as Boston and OJ.



🧠 Key Learning Outcomes

	•	Applied supervised learning techniques such as linear regression, decision trees, and gradient boosting.
  
	•	Conducted model selection using k-fold cross-validation and AIC/BIC comparison.
  
	•	Analyzed regularization methods (ridge, lasso) and their effects on overfitting and model stability.
  
	•	Used smoothing splines and GAMs (Generalized Additive Models) for non-linear pattern discovery.
  
	•	Evaluated and compared predictive models through error metrics and bias–variance analysis.


⚙️ Tools & Environment

	•	Language: R (v4.3+)
  
	•	Packages: ISLR, MASS, boot, glmnet, pls, tree, gam, gbm
  
	•	Rendering: .Rmd → .pdf via rmarkdown::render()
  
	•	IDE: RStudio


🔒 Notes
