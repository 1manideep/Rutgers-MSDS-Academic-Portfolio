🧩 Data Structures and Algorithms — Coursework Archive

This folder contains selected assignments from the Data Structures and Algorithms course completed as part of the M.S. in Data Science at Rutgers University.
The course emphasized algorithmic thinking, computational efficiency, and implementation of classical data structures in Python.

📂 Contents

	•	Manideep_HW4.py	-- Implementation of core data structures including stacks, queues, and linked lists. Demonstrates encapsulation, inheritance, and time-complexity annotations.
  
	•	Manideep_HW5.ipynb --	Notebook on dynamic programming, recursion, and optimization problems with visualization of complexity growth.
  
	•	Manideep_H7.py --	Recursive algorithms and divide-and-conquer paradigms — includes merge sort, binary search, and matrix operations.
  
	•	Manideep_HW8.py --	Graph algorithms: BFS, DFS, topological sort, and shortest path using adjacency lists.
  
	•	manideep-HW9.py --	Hash tables and collision resolution methods (linear probing, chaining). Includes runtime benchmarking.
  
	•	q1,q2.py --	Early coursework problems — string reversal, recursion, and stack operations.
  
	•	q3.py --	Tree traversal and depth computation implementations.



🧠 Key Learning Outcomes

	•	Implemented and analyzed fundamental data structures: arrays, stacks, queues, linked lists, trees, graphs, and hash tables.
  
	•	Practiced algorithmic problem-solving using recursion, dynamic programming, and divide-and-conquer methods.
  
	•	Evaluated time and space complexity (Big O) for iterative and recursive algorithms.
  
	•	Designed clean, modular Python programs emphasizing readability and computational performance.
  
	•	Used Jupyter for algorithm visualization and experimentation, demonstrating theoretical behavior with empirical timing.
