📈 Regression and Time Series Analysis — Coursework Archive

This folder contains assignments and project work from the Regression and Time Series Analysis course completed as part of the M.S. in Data Science at Rutgers University.
The course emphasized predictive modeling, time series forecasting, and model evaluation using both statistical and computational methods.
Work was completed in Python (Jupyter Notebooks) and R, combining theoretical derivations with applied analysis.


📂 Contents

	•	HW1.ipynb / HW1.pdf --	Exploratory regression analysis and parameter estimation using ordinary least squares (OLS).   
  
	•	HW2.pdf, hw2-1.pdf, hw2__.pdf	--	Polynomial and multiple regression models; testing non-linearity, residual diagnostics, and model refinement.
  
	•	HW4-Q3.pdf, Q1,Q4.pdf, Q2,3 (part Q4).pdf --		Analytical solutions and code derivations for regression exercises on bias–variance and cross-validation.
  
	•	Manideep_HW4.pdf – Manideep_HW8.pdf --		Sequential homework set covering autoregressive (AR), moving-average (MA), ARIMA, and seasonal decomposition methods; includes model fitting and prediction evaluation.
  
	•	Manideep_HW5.pdf --		Applied forecasting on real datasets; analysis of autocorrelation and partial autocorrelation (ACF/PACF).
  
	•	Manideep_HW6.pdf --		Exponential smoothing, stationarity testing, and differencing to achieve model stability.
  
	•	Manideep_HW7.pdf --		Multivariate regression and dynamic regression models integrating lagged predictors.
  
	•	Manideep_HW8.pdf --		Forecast evaluation — comparing ARIMA and exponential models via RMSE and residual analysis.
  
	•	manideep-report.pdf --		Final report summarizing model performance and forecasting outcomes.
  
	•	code.ipynb --		Supplementary notebook consolidating Python implementations for regression and time series experiments.



🧠 Key Learning Outcomes

	•	Built and evaluated simple and multiple regression models using OLS and polynomial fitting.
  
	•	Conducted diagnostic analysis — multicollinearity, residual normality, and leverage detection.
  
	•	Applied time series modeling techniques: AR, MA, ARIMA, and exponential smoothing.
  
	•	Assessed stationarity through ACF/PACF, unit-root testing, and differencing strategies.
  
	•	Designed forecasting pipelines with performance evaluation using MAE, MSE, and RMSE metrics.
  
	•	Compared model generalization across cross-validated regression and time-based splits.
